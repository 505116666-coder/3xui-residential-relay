# 开发与测试

脚本版本 **1.1.1**，面板固定 **3X-UI v3.7.0**。本次管理功能已在用户现有 Linux VPS 完成真实 API 和节点链路验证，详见验证记录。全新安装/ACME 申请的完整测试仍需一次性 VPS；现有部署验证不等于重新安装验收。

## 单一源码与打包

仅编辑仓库中的 `deploy-3xui-dual.py`，Shell 启动部分在 `scripts/launcher.sh`。不要手动修改生成的安装包。

```bash
python3 scripts/build.py
python3 scripts/build.py --check
python3 -m unittest discover -s tests -p 'test_*.py'
bash -n deploy-3xui-dual.sh
```

生成单文件 `3xui-residential-relay.sh`、同内容的旧文件名兼容入口 `deploy-3xui-dual.sh` 和 `SHA256SUMS`。`python3 scripts/build.py --sync-workspace` 另外同步父目录的安装脚本、Python 副本和卸载脚本，仅供当前视频工作目录使用。普通仓库开发无需这个参数。

`--version` 可在不安装的情况下读取脚本和面板版本。修改版本时同时更新 Python 与 launcher 中的版本文字；构建工具检查两者一致。

SHA256SUMS 用于检查发布文件是否一致，不替代可信发布来源。建议通过 Git tag 发布已经验收的版本，安装命令固定到该 tag。

## 本地测试范围

- Python 测试：路由、API 格式、添加、更新、删除、恢复、全节点检查、脱敏诊断、终端输出和模拟卸载。
- 真实 Xray：本机 TLS/HTTP/DNS/SOCKS 服务，虚构认证，验证 REALITY TCP/UDP 与上游失败不回退。

```bash
XRAY_TEST_BIN=/absolute/path/to/xray python3 tests/integration_xray.py
```

这些测试均不能证明真实面板端到端兼容、住宅供应商连通性、ACME 证书申请或公网入口可达。

## 真实面板端到端入口

`tests/e2e_panel.py` 必须在**全新的一次性 Ubuntu/Debian 测试 VPS**上以 root 运行。它会安装真实面板、申请 IP 证书、启动服务，并使用真实住宅代理。发现现有面板或部署目录会拒绝运行。

准备权限为 0600 的 JSON 配置，结构如下，填入专用测试凭据：

```json
{
  "email": "your-test-email@example.com",
  "proxy": {
    "host": "your-residential-gateway.example.com",
    "port": 1080,
    "username": "your-test-user",
    "password": "your-test-password"
  }
}
```

可选 `replacement_proxy` 字段，结构同 `proxy`，用于额外验证更换真实上游。未提供时结果记录 `replacement_tested: false`。

```bash
chmod 600 /root/e2e-config.json
python3 tests/e2e_panel.py --disposable-vm --config /root/e2e-config.json
```

必须满足首页的网络和证书申请条件，包括 TCP 80、正确邮箱和代理商白名单。测试会真实调用面板 API、systemd、Xray、HTTPS 证书申请及出口检测。故障用例在面板实际写入新增入站后丢弃一次响应，验证真实回滚；不使用假面板来替代该流程。

流程：安装 → 全节点检查 → 丢失新增响应并回滚 → 正常新增 → 全节点检查 → 改名 → 可选更换上游 → 删除追加节点 → 再次检查，并核对原始路由与原始入站未改变。

成功报告保存在测试 VPS 的 `/root/3xui-dual/e2e-result.json`。失败保留现场供排查；日志和部署记录可能含凭据，勿公开。测试不会自动卸载，检查后销毁这台专用测试 VPS。仍需独立客户端确认公网节点入口可达。

## 已有服务器的管理功能实测

`tests/live_validation.py` 在明确获准的已安装服务器上执行，使用已有住宅代理凭据创建本机监听的临时节点。会重启代理服务，并测试新增、丢失响应后的回滚、改名、替换和删除；最后核对原始状态、路由和全部入站，并复查原节点连通性。结果与私有恢复基线保存在部署目录中。

2026-09-13 已在用户授权的实际 VPS 通过此流程。脚本只针对已有部署；不得把它用作任意服务器的无人值守巡检。
